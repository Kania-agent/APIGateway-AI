# APIGateway AI

Intelligent API gateway management dashboard powered by MiMo V2.5.

## Features

- Tech-focused dark theme with cyan/blue accents
- Endpoint table with method, path, latency, and status
- Rate limit gauges (CSS radial)
- Visual routing flow diagram
- Real-time request monitoring

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- No external dependencies or frameworks

## Usage

Open `index.html` in a browser. Monitor endpoints, view rate limits, and inspect the routing flow diagram.

## AI Engine

Powered by **MiMo V2.5** — Nous Research's API management AI model.
